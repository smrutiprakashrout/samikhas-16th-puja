# V00 — Set up this computer and prove the pipeline
Goal: after this task, `npm run studio` opens Remotion Studio, `npm run still` and `npm run render` work, fonts (including Odia) render, audio is muxed, and nothing else exists yet. No scenes. No design.
Do exactly the steps below in order. Stop and tell the owner if a step says STOP.

## 1. Check the computer
1. Detect the OS (`uname -s`; on Windows use `ver`). Print it.
2. `node -v` must be **v20 or newer** (v22 LTS preferred). If lower or missing: STOP and tell the owner to install Node 22 LTS from nodejs.org, then re-run this task. Also `npm -v`.
3. Check that this folder is `video/` inside the website repo: `../package.json` must exist and `AGENTS.md`, `PLAN.md`, `TASKS.md`, `docs/FILM-GUIDE.md`, `assets-src/kalash.svg`, `src/content.video.ts` must exist here. If any is missing: STOP and tell the owner to copy the kit's `video/` folder into the repo.
4. Linux only: Remotion's browser needs system libraries. Ask the owner for permission, then (Debian/Ubuntu): `sudo apt-get update && sudo apt-get install -y libnss3 libdbus-1-3 libatk1.0-0 libasound2t64 libxrandr2 libxkbcommon-dev libxfixes3 libxcomposite1 libxdamage1 libgbm-dev libcups2 libatk-bridge2.0-0` (use `libasound2` if `libasound2t64` does not exist). macOS and Windows need nothing extra.

## 2. Create the project files (inside `video/` only)
`package.json`: name `invite-video`, `private: true`, **do not** set `"type": "module"`. Scripts:
```
"sync":   "node scripts/sync-assets.mjs",
"studio": "npm run sync && remotion studio src/index.ts",
"still":  "npm run sync && remotion still src/index.ts",
"render": "npm run sync && remotion render src/index.ts Invite out/samikshya-16th-puja-9x16.mp4 --codec=h264 --crf=18 --pixel-format=yuv420p --audio-codec=aac",
"render:share": "npm run sync && remotion render src/index.ts Invite out/samikshya-16th-puja-9x16-share.mp4 --codec=h264 --crf=24 --pixel-format=yuv420p --audio-codec=aac",
"compare": "node scripts/compare.mjs",
"typecheck": "tsc --noEmit"
```
(`npm run still -- <CompId> <outfile> --frame=30` passes extra arguments through.)
Install, all **pinned to the same exact version** (no `^`, use `--save-exact`): `remotion`, `@remotion/cli`, `@remotion/google-fonts`, `@remotion/media-utils`, `@remotion/transitions`. Use version **4.0.545** (the latest when this kit was written). If it fails to install, use the newest version shown by `npm view remotion version` for ALL of them. Also `react@19 react-dom@19` (fall back to 18 only if peer-dependency errors) and dev: `typescript @types/react @types/react-dom`.
`tsconfig.json`: `target ES2022`, `module ESNext`, `moduleResolution Bundler`, `jsx react-jsx`, `strict true`, `allowJs true`, `checkJs false`, `skipLibCheck true`, `noEmit true`, `include ["src","scripts"]`.
`remotion.config.ts`: `Config.setVideoImageFormat('jpeg'); Config.setOverwriteOutput(true);`
`.gitignore` (in `video/`): `node_modules`, `out`, `public`, `src/generated`, `.DS_Store`.
Make `video/out/` and `video/qa/` (keep `qa/.gitkeep`).

## 3. `scripts/sync-assets.mjs` (Node, no dependencies, works on Windows/macOS/Linux)
Run from `video/`. It copies, creating folders as needed, and prints one line per group:
- `../assets/img/*` → `public/img/`
- `../assets/svg/*.svg` → `public/svg/` (skip files starting with `_`)
- `../assets/audio/bgm.mp3` → `public/audio/bgm.mp3`
- `../src/sections/00-gate/door.svg` → `public/svg/door.svg`
- `assets-src/*.svg` → `public/svg/` (this brings `kalash.svg`)
- `../src/content.js` → `src/generated/content.js`, `../src/core/garland.js` → `src/generated/garland.js`; each gets a first line `// GENERATED by scripts/sync-assets.mjs. DO NOT EDIT.`
- It also writes `src/generated/content.d.ts` with `export const content: any;` and `src/generated/garland.d.ts` with `export function createGarland(seed?: number): any;`.
If a source file is missing it prints a warning (not an error) except `content.js` (error).

## 4. Minimal Remotion app (test only)
- `src/index.ts`: `registerRoot(RemotionRoot)`.
- `src/fonts.ts`: load with `@remotion/google-fonts` and **explicit weights and subsets** (no loading of every subset):
  - Cormorant Garamond: `normal` weights 400, 500, 600 and `italic` weights 400, 500; subsets `['latin']`.
  - DM Sans: `normal` weights 400, 500; subsets `['latin']`.
  - Noto Serif Oriya: `normal` weights 500, 600; subsets `['oriya','latin']`.
  Export `fontFamilies = { display, sans, odia }` using each loader's `fontFamily` value. `loadFont` already blocks rendering until the font has loaded.
- `src/Root.tsx`: register ONE test composition `FontTest`: 1080×1920, 30 fps, 90 frames, with `import './fonts'`.
- `src/FontTest.tsx`: ivory background (#FBF3E4), ink text (#232B25), centred column, showing: (a) `videoContent.satya.titleA + ' ' + titleB` in Cormorant 500 at 140 px with "Puja" italic in #B25D17; (b) `videoContent.satya.time` in Cormorant 500 at 300 px, #B25D17; (c) a DM Sans 500 label, 40 px, uppercase, letter-spacing .24em: `content.event.dateLong`; (d) `content.invocation.sanskrit` and the four `content.shloka.lines` in Noto Serif Oriya 600 at 70 px, one per line; (e) a frame counter in DM Sans 400 at 36 px (`useCurrentFrame()`), proving frames advance. Add `<Audio src={staticFile('audio/bgm.mp3')} volume={0.5} />` (if the installed Remotion marks `Audio` from `remotion` as deprecated in favour of `Html5Audio`, use that).

## 5. Prove it
1. `npm run typecheck` passes.
2. `npx remotion browser ensure` (downloads the headless Chrome once; needs internet). If it fails, report the error text to the owner.
3. `npx remotion compositions src/index.ts` lists `FontTest`.
4. `npm run still -- FontTest qa/V00-fonts.png --frame=30`.
5. Test render: `npx remotion render src/index.ts FontTest out/V00-test.mp4 --codec=h264 --pixel-format=yuv420p --audio-codec=aac`.
6. `npx remotion ffprobe out/V00-test.mp4` must show: video h264, 1080×1920, 30 fps, and an audio stream (aac). Report these four facts.
7. Open `qa/V00-fonts.png` and look at it. Expected: all five items visible, Odia text readable with joined conjuncts (for example the first word of the invocation shows `ଶ୍ରୀ` as one joined shape, not a row of separate marks and not empty boxes).
